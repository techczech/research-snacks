# Method and provenance

Prepared with Codex using the existing Sketch Engine account and direct documented API endpoints. The corpus contexts are primary lexical evidence; official corpus/API/statistics pages explain collection and calculation conventions. Interpretation and coding were performed by the agent from wider contexts, rather than by an independent panel of human annotators.

The source archive preserves completed JSON responses, corpus metadata, and mechanically converted verbatim official documentation. Failed broader searches are recorded without absence claims. The newer web corpus contributed no successful query evidence. No credentials are saved.

The canonical Markdown with YAML is compiled by Python/PyYAML and pandoc to a normal site, then packaged by inlining CSS and JavaScript. Machine-derived statistical tables are editable JSON. The same Markdown produces the narrative, UI labels and curated KWIC rows. Sources remain separate from styling and interaction code.

Strict packaging audit, formula checks, a representative source-edit rebuild, headless file:// desktop/mobile checks, table/filter/sort/CSV/search tests and print generation passed. The public reading experience is offline. Detailed check results are in the entry changelog.

The reference corpora are historically and compositionally unmatched; the American sample is especially sparse and has POS errors. The selected food annotation and targeted web retrieval cannot support a population-level construction preference or a dialectal prohibition.
